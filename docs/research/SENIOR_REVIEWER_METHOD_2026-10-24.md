# 一位资深合规审阅人怎样看一份营销材料

2026-10-24。本文配合同名 JSON 配置文件使用，写给没有法律背景的读者。场景是新加坡一家金融机构的合规部门：市场同事送来一条准备发在社交媒体上的投资产品推广文案，合规要在发布前看一遍。文中的公司、产品、人物和清单都是虚构的演示材料。

## 一、真实的工作顺序

资深审阅人大致按六步走：前两步决定后面值不值得做，中间三步逐句和整体检查，最后写意见、留档。

### 1. 受理：先弄清这是什么、给谁看、谁在发

审阅人拿到材料，先读背景，文案放到后面。他要弄清几件事：
- 这是什么产品，要给哪类人看；
- 发在哪个平台、用什么形式；
- 是公司自己的账号发，还是找了外部博主，公司有没有付钱；
- 市场同事这次交了什么材料，还有什么没交。

先看背景，是因为同一句话放在公司官网和放在博主的个人账号上，要求完全不同。背景没弄清，后面每一条判断都可能建立在错的前提上。

这一步最怕两件事。一是材料版本不对：审的是初稿，发出去的是改过的稿子。二是市场同事没说清推广关系，审阅人按“自有账号”审了，实际是付费找人发的。

### 2. 前置判断：这个产品现在能不能公开推广

有些产品根本不允许面向大众做广告。新加坡《证券及期货法》第 300 条写得很直接：需要招股说明书的基金，没有按法定方式就不能打广告，也不能发任何“可能引导人去买”的内容。招股说明书是基金发售前必须向监管注册的说明文件。只面向认可投资者（资产或收入达到法定门槛的投资者）的私募产品，更不能发到公开的社交媒体上。

这一步必须在改措辞之前做完。产品本身不能公开推广时，文案写得再规范也没有意义。而且一旦开始改措辞，对方很容易以为“改好就能发”。

这一步最怕的是：背景里没写产品类型和受众，审阅人就默认它是普通的零售基金，也就是卖给普通个人的基金。他一路审到底，结果产品只能给认可投资者看。

### 3. 列声明、配证据：每一句能被核实的话都要有出处

审阅人把文案里所有“可以被证明或证伪”的话挑出来，例如：
- 收益数字，比如“过去三年年化 9.2%”；
- 奖项和比较，比如“连续两年获奖”“跑赢同类”；
- 暗示安全的说法，比如“波动极低”；
- 关于推广关系的话，比如“这不是广告”；
- 公司名称和风险提示。

每一条旁边写两样东西：这类说法通常要什么证明，市场同事这次给了没有。

为什么这样做？监管要求广告“不虚假、不误导、公平平衡”。审阅人判断不了一个数字对不对，他能判断的是有没有人对这个数字负责、依据能不能追溯。收益率要有计算口径和期间，奖项要有颁奖方和年份，比较要有同口径的对手数据。

这一步最怕两种相反的错误。一是把“没给证据”当成“说法有问题”，逼市场同事改掉一句其实有依据的话。二是把“背景里说了一句有依据”当成“已经核实”，结果没有留下任何可以回查的材料。

### 4. 对照清单：一条一条过公司自己的标准

公司合规部门会把监管要求和内部政策写成一份清单。每一条写明四样东西：
- 首选的做法是什么；
- 退一步能接受什么；
- 碰到问题谁来决定；
- 有没有一句事先批准过的标准措辞可以直接用。

审阅人拿文案逐条对照，每条给出四种结果之一：符合；不一致，也就是文字本身写得不对；在可接受退让内；需补材料，也就是要等证明交来才能判断。

为什么要逐条过，不凭感觉通读？逐条过能保证每条都看到，另一个人复核时也知道哪条看过、哪条没看。清单里还有几条只在特定发布形式下适用。比如“视频开头要有画面文字披露推广关系”，静态图文不用看；“风险提示在最终画面要能读清”，纯文字帖不用看。

这一步最怕两种错误：对不适用的条目索要材料，比如给一张静态图片要“口播稿”；以及把背景里已经写明的事实再问一遍。这两种错误都会让市场同事觉得合规在添乱。

### 5. 整体印象：退后一步，当作读者只看这一条

逐条过完，审阅人会把文案从头到尾再读一遍。这次不看单句，看整体：
- 好处讲了多少，风险讲了多少；
- 风险是不是只剩一句套话；
- 关键条件是不是被“详见链接”打发了；
- 有没有制造紧迫感。

MAS（新加坡金融管理局）的数字广告指引明确要求：每一条帖子单独看都不能误导，不能靠别的页面来“平衡”。

单独列这一步，是因为一篇文案可能每一句都挑不出毛病，合在一起却只剩下“收益高、很安全、快来买”。单句检查抓不住这种问题。

这一步最怕的是：所有单项都“没问题”，于是整篇放行，没有人退后看过一眼。

### 6. 处理意见与留档：分清要改的、要补的、要别人拍板的

最后，审阅人写两份东西。
- 给市场同事：哪几句要改、改成什么，哪几份材料要补、用来证明什么。
- 给自己的负责人：每条的状态，哪几条需要负责人决定，以及审阅人建议怎么处理（改了再交、补齐材料再审、可以交负责人批准）。

分两份写，是因为两边要的东西不同。市场同事需要能直接动手的清单，负责人需要决策依据。两者混在一起，前者看不懂，后者看不全。

留档是为了日后有人投诉或监管来查时，能说清当时看了哪一版文案、用的哪一版清单、手上有哪些材料、谁做了什么决定。MAS 指引写明，高管可以把工作委派出去，但责任委派不掉。没有留档，这个责任就没法追溯。

## 二、他绝不交给 AI 决定的事

一共五件。

产品能不能公开发售。这是法律问题，答案取决于产品文件和监管批复，文案里没有这个信息。AI 只能把背景里写的三件事登记下来；背景没写，就停下来问人。

例外和退让。清单里的“可接受退让”是公司事先想清楚的。没有写进清单的退让，AI 不能临场发明。一次退让会成为下一次的先例，这个口子只能由人开。

证据够不够。AI 可以说“背景写了没给计算依据”，不能说“这个 8% 是对的”。一份业绩数据的口径合不合理，要看原始文件，还要有人对它签字。

取决于事实的措辞。比如博主是否持牌，也就是是否是金融机构委任、可以提供投资建议的代表。持牌和不持牌要写的话完全不同，写错一种，就是往另一个方向误导。这类句子不配批准文本，由负责人定稿。

最终结论。预审的输出是意见和建议，不是批准。“可以发”这三个字必须由有权限的人说，而且要留下他说过的记录。

原因只有一个：AI 出错时和它正确时，看起来一模一样。在一个会被监管追责的流程里，每一个改变结果的判断都要能对应到一个人。

## 三、这套方法怎样落到产品里

括号里是配置文件中的字段名。

| 工作步骤 | 产品里对应的东西 | 谁在判断 |
|---|---|---|
| 受理 | 第一步 Skill（受理与声明清单）的受理登记部分（intake）：从背景抄录产品、受众、推广关系、发布者、已交材料 | 模型只抄录，不推断；背景没写就填“未说明” |
| 前置判断 | 清单第 R0 条，标为前置条件（gate）。没通过时结果标红，提示先确认前置条件，见表下说明 | 模型只读背景；标不标红由代码决定 |
| 列声明、配证据 | 第一步 Skill 的声明清单（items）：每条声明带类型、原文引用、需要什么证据、背景里有没有给。代码逐字核对引用是否真的出自文案 | 模型整理；引用真伪由代码核对 |
| 对照清单 | 第二步共用的对照 Skill，一次只看一条。R1–R11 每条写清首选、退让、谁决定、批准文本。哪些条目适用，由代码按发布形式筛选（R3、R5、R10 带适用条件 applies_when） | 模型四选一；适用性、严重度分流、批准文本替换由代码做 |
| 整体印象 | 清单第 R7 条，单独一条，只看通篇平衡 | 模型判断，交合规负责人 |
| 处理意见 | 第三步 Skill（审阅意见回复）：给市场同事的改句与补件清单，给负责人的备注与建议结论。写作要求里写死：只按发布形式索要材料 | 模型起草；结论标明“建议，由负责人决定” |
| 留档 | 每次运行保存文案版本、清单版本、背景和各条结果 | 代码 |

R0 什么时候算没通过：它被判为“不一致”“需补材料”“适用范围待确认”，或者模型漏答、调用失败。这时结果顶部标红，提示“先确认前置条件，暂不看措辞”，给市场同事的回复只问这一件事。其余条目照常检查并显示，系统不会中途停掉。R0 只是被反向复核标为“需人工检查”时，结果同样标红，但提示的是“前置条件需人工确认”：交给人确认，其余照常审阅、照常回复。

落到产品时，还定了两条硬规则。

第一，“需补材料”和“不一致”是两种不同的结果，代码分开处理。前者汇总成补件清单发给市场同事，后者才触发改句和升级。

第二，对照 Skill 的说明保持通用，不写任何金融内容，因为同一个 Skill 也用在保密协议审阅上。所有金融领域的要求，都写在清单条目和写作要求里。

## 四、名词表

- **合规**：按法律、监管规定和公司自己的规矩办事。合规部门的工作，就是在事情发生前检查有没有按规矩来。
- **披露**：把读者有权知道的事写清楚，比如“这是付费推广”“投资可能亏损”。
- **举证／证据支持**：一句话被人追问“你凭什么这么说”时，能拿出来的材料。收益率的证据是计算表，奖项的证据是获奖函。
- **首选立场**：公司最希望文案写成的样子。
- **可接受退让**：达不到首选时，公司事先同意可以接受的次一级做法。没写进清单的，不算。
- **批准文本**：公司事先审定过的一句标准话，碰到对应问题可以直接替换进文案。
- **前置条件**：必须先满足才能往下审的事。它不满足时，改措辞没有意义。
- **集合投资计划**：把很多人的钱凑在一起，由专业机构去投资的安排。平常说的基金就是最常见的一种。
- **零售投资者**：普通个人投资者。监管对面向他们的广告要求最严。
- **认可投资者**：资产或收入达到法定门槛的个人或机构。面向他们的产品可以少一些保护，但也因此不能随便向大众宣传。
- **招股说明书／产品重点说明书**：基金正式发售前必须准备并向监管注册的说明文件。前者是全本，后者是几页纸的摘要。广告里要告诉读者去哪里拿，并提醒投资前先看。
- **牌照／持牌代表**：在新加坡提供投资建议或销售投资产品，机构要有牌照，具体的人要是机构委任的代表。没有这个身份的人，不能给人理财建议。
- **金融网红**：在社交媒体上讲理财、带产品的博主。金融机构付钱请他们发的内容，监管直接当作广告看待，并要求写明他们是否持牌。
- **MAS**：新加坡金融管理局，新加坡的金融监管机构。
- **ASAS**：新加坡广告标准管理局，行业自律组织，管所有行业的广告，包括社交媒体上的赞助内容怎么标。
- **SFA**：新加坡《证券及期货法》，管证券、基金等投资产品发售和广告的主要法律。
- **整体印象**：不看单句，把整篇文案当作读者唯一看到的内容，问它给人的总体感觉是否误导。
- **留档**：把审过的版本、用的标准、手上的材料和谁做了什么决定保存下来，供日后查证。
