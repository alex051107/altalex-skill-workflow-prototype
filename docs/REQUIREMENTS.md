# 题目要求逐条对照

这一页把题目的每条要求拆开，写明在哪里交付、做到了没有。“提交说明”指 [SUBMISSION](SUBMISSION.md)，“验证记录”指 [VALIDATION](VALIDATION.md)，“AI 使用说明”指 [AI_USAGE](AI_USAGE.md)。

状态分三种：做到、部分做到、没做。部分做到和没做都写明原因。

## 测试目标

| 题目要求 | 在哪里 | 状态 |
|---|---|---|
| 理解业务 → 识别待确认信息 → 开展调研 → 制定计划 → 设计方案 → 开发实现 → 验证结果 | 提交说明 A 到 E 依次写这七步 | 做到 |
| 对最终方案、代码和验证结果负责，能解释关键决策 | 提交说明 C“计划改了哪些地方，为什么”；AI 使用说明“我不让 AI 决定的事” | 做到 |

下表最后一列的“自检”指 `scripts/smoke_d1_d5.py`。2026-10-25 我从 GitHub 重新克隆，在演示模式和 DeepSeek 真实模型下各跑了一遍，全部通过。
